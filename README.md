# 🎥 جمهور AI المباشر (AI Live Audience)

تبث مباشرة من الكاميرا أو الشاشة، ويتفاعل معك جمهور من شخصيات AI كأنهم جمهور حقيقي على Twitch أو TikTok Live.
كل شخصية لها اسم وصورة ولهجة وجنسية وطباع وأسلوب كتابة خاص فيها، وتتذكر البثوث السابقة.

## التشغيل محلياً
المتطلبات: **Node.js 22.5 أو أحدث** (يفضّل 22 LTS أو 24). ما يحتاج أي برامج ترجمة (compilers)، لأنه يستخدم SQLite المدمجة في Node.

```bash
npm install
npm start
```
بعدها افتح: **http://localhost:3000**

- الكاميرا والمايك تشتغل على `localhost` مباشرة. للجوال أو أي جهاز ثاني لازم يكون الرابط **HTTPS** (شوف قسم النشر).
- النداء الصوتي (تقول "يا luna" بصوتك) يحتاج **Chrome أو Edge**.
- كشف الأشياء بالكاميرا يحمّل نموذج TensorFlow.js من الإنترنت أول مرة.
- البيانات تنحفظ في `data/audience.db` (SQLite)، والصور في `data/avatars` و`data/uploads`. غيّر المكان بـ `DATA_DIR=/path`.

## الذكاء الاصطناعي (اختياري)
التطبيق **يشتغل كامل بدون أي مفتاح**: فيه محرك محلي مبني على قوالب لهجات حقيقية وقواعد سلوك، ويمنع التكرار.
لو تبي ردود أذكى:
- من صفحة **الإعدادات** اختر المزود (OpenAI / xAI Grok / Anthropic / OpenRouter / Groq / أي خدمة متوافقة مع OpenAI) والصق المفتاح، أو
- عرّف متغير بيئة قبل التشغيل: `OPENAI_API_KEY` أو `XAI_API_KEY` أو `ANTHROPIC_API_KEY` أو `OPENROUTER_API_KEY` أو `GROQ_API_KEY` (ويمكن تحديد `LLM_MODEL` و`LLM_BASE_URL`).

مع المفتاح، النصوص تنكتب بالنموذج، لكن نظام الأدوار والتوقيت ومنع التكرار وفلتر الأمان تبقى محلية. لو صار أي خطأ يرجع للمحرك المحلي تلقائياً.
مزود يدعم الصور (مثل OpenAI) يفعّل زر "❓ وش هذا؟"، وOpenAI يفعّل كمان توليد صور الحسابات بالذكاء الاصطناعي.

## النشر (Deploy)
يحتاج خادم Node يشغّل عملية دائمة، يدعم **WebSocket**، وفيه **قرص دائم** لمجلد `data/`.
- **Docker**: `docker build -t ai-audience . && docker run -p 3000:3000 -v $(pwd)/data:/app/data ai-audience`
- **Render / Railway / Fly.io**: أمر البناء `npm install` وأمر التشغيل `npm start`. اربط قرص دائم (Volume) على `/app/data` أو عرّف `DATA_DIR`، والمنصة توفر HTTPS تلقائياً.
- **VPS**: شغّله بـ `pm2 start npm -- start` وخلّ قدامه Nginx أو Caddy مع HTTPS (لازم تمرر WebSocket على المسار `/ws`).
- **حماية بكلمة مرور**: عرّف `APP_PASSWORD=كلمة_سر` وبيطلب المتصفح كلمة المرور.
- **ملاحظة**: منصات Serverless مثل Vercel وNetlify ما تناسبه، لأنه يحتاج WebSocket وقاعدة SQLite على قرص دائم.

## الصفحات
1. **قبل البث**: تحدد فيها تركيبة الجمهور (العدد، البنات والأولاد، نسبة معينة، الكل عشوائي، أو كلهم من اختيارك)، والوجوه المألوفة، واحتمال دخول أجانب، وأوزان الجنسيات. وفيها كمان مستوى الأدب (محترم جداً، عادي، ساخر، قليل أدب، طقطقة قوية، سب خفيف، عشوائي)، ومستوى الطقطقة والسب الخفيف والنشاط، ونسبة الهادئين وكثيري الكلام، والتكرار، والنقاش بين الشخصيات، وتشغيل الذاكرة والبحث. وتقدر تحفظ الإعدادات كقالب، وتشوف معاينة الجمهور وتعدّل الأسماء والصور وتبدّل أي شخصية.
2. **البث المباشر**: كاميرا أو مشاركة شاشة، ونداء صوتي، وكشف الأشياء مع إطار حول الشيء، وتسجيل البث. فيه أزرار للأحداث السريعة (خسرت، فزت، نكتة، حدث مهم، لعبة جديدة)، ودردشة فيها مؤشر "يكتب…"، وردود أفعال بالإيموجي. وتقدر تدير الجمهور: إسكات، منع من الرسائل، إزالة، طرد، حظر وفك حظر، إعادة، إضافة شخصيات عشوائية أو من المكتبة، وتحديد حد أقصى للجمهور.
3. **الشخصيات**: المكتبة كاملة، تعدّل فيها الهوية والطباع وأسلوب الكتابة واللهجات المفهومة والصورة (من المكتبة أو ترفع صورة أو تولّد وحدة)، وتشوف المفضلة والسمعة والذكريات والكلمات اللي تعلمتها كل شخصية وعلاقاتها بالباقين.
4. **البثوث السابقة**: أهم اللحظات، والحضور، وسجل الدردشة كامل.
5. **الذاكرة والقاموس**: الكلمات اللي تعلموها (مؤكدة أو تخمين)، والمعرفة المكتسبة عن الأشياء، والذكريات. تقدر تمسح أي شي منها أو توقف الذاكرة.

## كيف تتعامل معهم
- **تنادي شخصية**: اكتب `@الاسم` أو "يا الاسم"، أو قلها بصوتك. يتعرف حتى على "يا لونا" لـ luna.exe، و"يا قهوة" لـ ☕.
- **تعلّمهم كلمة**: اكتب «زقنبي يعني شخص مزعج». ولو سألوك "وش يعني X؟" فردّك اللي بعده ينحفظ كمعنى للكلمة.
- **تعرّفهم على شيء**: لما يسألون "وش هذا اللي بيدك؟" قل «هذا اسمه يد بلايستيشن 5».
