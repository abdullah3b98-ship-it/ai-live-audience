# جمهور AI المباشر (AI Live Audience)

تبث مباشرة من الكاميرا أو الشاشة، ويتفاعل معك جمهور من شخصيات AI كأنهم جمهور حقيقي على Twitch أو TikTok Live.
كل شخصية لها اسم وصورة ولهجة وجنسية وطباع وأسلوب كتابة خاص فيها، وتتذكر البثوث السابقة.

## التشغيل محلياً
المتطلبات: **Node.js 22.5 أو أحدث** (يفضّل 22 LTS أو 24). ما يحتاج أي برامج ترجمة (compilers)، لأنه يستخدم SQLite المدمجة في Node.

```bash
npm install
npm start
```
بعدها افتح: **http://localhost:3000**

- الكاميرا والمايك تشتغل على `localhost` مباشرة. للجوال أو أي جهاز ثاني لازم يكون الرابط **HTTPS** (شوف قسم النشر).
- سماع اسمك بالصوت (اختياري، مطفي افتراضياً) يحتاج **Chrome أو Edge**، وكلامك **ما ينعرض** في الدردشة؛ يُستخدم بصمت عشان يعرفون إنك ناديتهم.
- مشاركة الشاشة تشتغل من متصفح الكمبيوتر (Chrome / Edge / Safari / Firefox). متصفحات الجوال ما تدعمها، ويطلع لك تنبيه واضح.
- الجمهور **يشوف الكاميرا تلقائياً** أول ما تشغلها: كشف أشياء في المتصفح (TensorFlow.js، يتحمّل من الإنترنت أول مرة)، ومع مفتاح يدعم الصور تنرسل لقطة كل ~35 ثانية للذكاء الاصطناعي. يتعلمون الأشياء الجديدة **بأنفسهم** ويتذكرونها في البثوث الجاية.
- البيانات تنحفظ في `data/audience.db` (SQLite)، والصور في `data/avatars` و`data/uploads`. غيّر المكان بـ `DATA_DIR=/path`.

## الذكاء الاصطناعي (اختياري)
التطبيق **يشتغل كامل بدون أي مفتاح**: فيه محرك محلي مبني على قوالب لهجات حقيقية وقواعد سلوك، ويمنع التكرار.
لو تبي ردود أذكى:
- من صفحة **الإعدادات** اختر المزود (OpenAI / xAI Grok / Anthropic / OpenRouter / Groq / أي خدمة متوافقة مع OpenAI) والصق المفتاح، أو
- عرّف متغير بيئة قبل التشغيل: `OPENAI_API_KEY` أو `XAI_API_KEY` أو `ANTHROPIC_API_KEY` أو `OPENROUTER_API_KEY` أو `GROQ_API_KEY` (ويمكن تحديد `LLM_MODEL` و`LLM_BASE_URL`).

مع المفتاح، النصوص تنكتب بالنموذج، لكن نظام الأدوار والتوقيت ومنع التكرار وفلتر الأمان تبقى محلية. لو صار أي خطأ يرجع للمحرك المحلي تلقائياً.
مزود يدعم الصور (مثل OpenAI) يخلي الجمهور يفهم اللقطات نفسها (مو بس الأشياء المعروفة)، وOpenAI يفعّل كمان توليد صور الحسابات بالذكاء الاصطناعي.

## النشر (Deploy)
يحتاج خادم Node يشغّل عملية دائمة، يدعم **WebSocket**، وفيه **قرص دائم** لمجلد `data/`.
- **Docker**: `docker build -t ai-audience . && docker run -p 3000:3000 -v $(pwd)/data:/app/data ai-audience`
- **Render / Railway / Fly.io**: أمر البناء `npm install` وأمر التشغيل `npm start`. اربط قرص دائم (Volume) على `/app/data` أو عرّف `DATA_DIR`، والمنصة توفر HTTPS تلقائياً.
- **VPS**: شغّله بـ `pm2 start npm -- start` وخلّ قدامه Nginx أو Caddy مع HTTPS (لازم تمرر WebSocket على المسار `/ws`).
- **حماية بكلمة مرور**: عرّف `APP_PASSWORD=كلمة_سر` ويطلع لك صفحة دخول (تنحفظ في كوكي 60 يوم، وتشتغل على الجوال). الأدوات مثل curl تقدر تستخدم Basic Auth.
- **لو الخادم أعاد التشغيل أثناء البث** (مثلاً الخطة المجانية في Render تنام بعد 15 دقيقة بدون زيارات)، صفحة البث تعيد الاتصال تلقائياً ويرجع الجمهور يدخل.
- **ملاحظة**: منصات Serverless مثل Vercel وNetlify ما تناسبه، لأنه يحتاج WebSocket وقاعدة SQLite على قرص دائم.

## الصفحات
1. **بث جديد**: صفحة قصيرة: اسمك، وش بتبث، عدد الجمهور، التركيبة (عشوائي / بنات أكثر / أولاد أكثر / نص نص)، والأسلوب، وزر **ابدأ البث**. المعاينة وتعديل الجمهور وكل الإعدادات التفصيلية (أعداد محددة، جنسيات، طقطقة، نشاط، قوالب…) مطوية تحت «عاين وعدّل الجمهور» و«إعدادات متقدمة».
2. **البث المباشر**: الكاميرا، مشاركة الشاشة، إنهاء، وزر «المزيد» (رؤية الجمهور، سماع اسمك بالصوت، التسجيل). الجمهور يدخل واحد واحد قدامك (رسالة دخول والعداد يزيد). زر ⚡ جنب الكتابة للأحداث السريعة (خسرت، فزت، نكتة…). تبويب «الجمهور» للإدارة: إسكات، منع، إزالة، طرد، حظر، إعادة، إضافة +1/+5 أو من المكتبة.
3. **الشخصيات**: المكتبة كاملة مع تعديل الهوية والطباع والصورة والذكريات والكلمات والعلاقات.
4. **السجل**: البثوث السابقة وأهم اللحظات والحضور والدردشة.
5. **الذاكرة**: الكلمات والأشياء اللي تعلموها والذكريات، مع إمكانية المسح.

## كيف تتعامل معهم
- **تنادي شخصية**: اكتب `@الاسم` أو "يا الاسم" (أو بصوتك إذا شغّلت السماع). يتعرف حتى على "يا لونا" لـ luna.exe.
- **التعلم**: يتعلمون بأنفسهم من الكاميرا ومن بعض (وإذا ما عرفوا كلمة يدورون عليها). تقدر تصححهم بالدردشة لو حبيت («هذا اسمه …» أو «كلمة يعني معنى») بس مو ضروري.
